Kurz einrichten

Diese Karte lädt echtes Kartenmaterial von MapTiler (siehe Leitfaden, Abschnitt 7.6). Dafür wird ein kostenloser MapTiler-Account und ein API-Key benötigt.

1. Account anlegen auf maptiler.com/cloud (Free-Tarif reicht zum Testen).
2. Im Dashboard den API-Key kopieren.
3. In dieser HTML-Datei die Zeile const MAPTILER_KEY = "DEIN_KEY_HIER"; (im Skript-Teil, ganz oben) mit dem eigenen Key ersetzen und Datei neu speichern/hochladen.

Dieser Hinweis verschwindet automatisch, sobald ein Key eingetragen ist.
